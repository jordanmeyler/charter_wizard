# Prefabs

`Window → Rune Magic → Authoring → Create / refresh prefabs` writes Item, Mite, Torch, Rod, Gate, Barrier, Plaque, Crystal, Charm, and Adept here. Drag them into the scene and set interactions on the Inspector.

Pack enemies are not prefab files — place them with **GameObject → Rune Magic → Enemies** or the Authoring window. `Main.unity` already has a few next to spawn.
