# Prefabs

`Window → Rune Magic → Authoring → Create / refresh prefabs` writes Item, Mite, Torch, Rod, Gate, Barrier, Plaque, Crystal, Charm, Fog, Chasm, and Adept here. Drag them into the scene and set interactions on the Inspector.

First-area puzzles (ice-caged fire stone, miasma + air stone, pit + earth stone) are under **GameObject → Rune Magic → First Area**. They are already in `Main.unity` under **Map / First Area**.

Pack enemies are not prefab files — place them with **GameObject → Rune Magic → Enemies** or the Authoring window.
